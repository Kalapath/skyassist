# SkyAssist

**Profit tracking for every part of Hypixel SkyBlock, in one mod.** Farming, mining, foraging, fishing, combat & slayers,
grinds (Zealots, Ghosts...), dungeons, Kuudra, Diana and Bazaar flipping each get their own HUD that switches
automatically with what you're doing.

**Display only.** This mod never clicks, walks, aims or plays for you. It reads your screen, chat and public price data. The only
things it does on its own: show information, and (optionally) put your mouse pointer back where it was when SkyBlock swaps one
menu for another. Optional inventory buttons send a command only when you click them.

## Highlights
- Profit, profit/h (AFK-proof), items, spent items, rare drops, shards, per activity; auto-reset after 15 min idle with history,
  lifetime totals and CSV export.
- "Best now": which crop / ore earns the most right now, using live Bazaar prices, your fortune and speed, the mayor and Jacob's contests.
- Bazaar flipping: flip finder, budget planner, automatic order tracking from chat, outbid / undercut alerts, flip profit log.
- Price alerts (`/alert enchanted diamond below 1500`), pickaxe ability ready alert, skill XP/h with time to level, slayer boss kill time,
  optional full-inventory warning.
- Tooltips: Bazaar / BIN / NPC prices, craft cost vs. buying, enchantment colors (perfect / great / good), mouse-wheel scrolling.
- Dungeons: secret finder, Three Weirdos, Blaze helper, F7 terminal solvers, chest profit.
- Calculator in Bazaar amount signs (`64x8=`) and `/calc`.
- Settings menu with search (O key or Mod Menu), HUD editor with move / resize / hide per panel and layout presets,
  first-time setup check, duplicate-feature detection for SkyHanni / Skyblocker / Odin.

## Requirements
Fabric Loader, Fabric API. Recommended: Hypixel Mod API. Optional: Mod Menu.
Builds for Minecraft 26.1.x and 26.2.

## Data sources
Hypixel public API (Bazaar, items, election), moulberry lowest BIN, NotEnoughUpdates item repository (recipes),
SkyKings Bot-Data (enchant levels), Elite Farmers API (Jacob's contests).
